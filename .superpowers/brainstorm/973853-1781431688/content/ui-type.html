What kind of UI should we build?

Pick the experience that fits how you (or users) will interact with Repo Intelligence.

A

Web Dashboard

A browser-based SPA (React/Vue) with pages for repos, capabilities, playbooks, query, approvals, and execution. Best for demos and non-technical users.

B

Static Admin UI

A lightweight HTML/CSS/JS single-page app served by the gateway (or nginx). No build step. Easier to maintain, less polish.

C

CLI TUI

A terminal user interface (e.g., Textual, Bubble Tea) for developers who live in the shell. Browse repos, capabilities, and run playbooks from the keyboard.

D

VS Code Extension

Integrate directly into the editor: query capabilities, run playbooks, and see approvals inside VS Code.
