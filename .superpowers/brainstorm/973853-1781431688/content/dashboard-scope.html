How much should the first dashboard cover?

We can ship a focused MVP first, or build the full control plane in one go.

A

MVP: Discover + Query

Pages: Repos, Capabilities, Playbooks, Natural-language Query.

Best for proving value fast. Users can ingest repos, browse generated artifacts, and search with plain English.

B

Standard: Discover + Execute + Approve

Pages: Repos, Capabilities, Playbooks, Query, Execute Playbook, Approvals.

Adds the ability to run playbooks and review AI-generated improvements. Good balance of power and scope.

C

Full Control Plane

Pages: Everything above + Feedback Metrics, Knowledge Search, Agent Orchestrator, User Settings.

Most complete, but more work. Use this if the dashboard is the primary product surface.
