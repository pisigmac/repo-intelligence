Architecture Highlights

  • Stack: React 18 + Vite + React Router + TanStack Query + Tailwind CSS
  • Location: new ui/ directory at repo root
  • Serving: production build served by a new nginx container; dev mode via Vite proxy to gateway
  • API client: auto-generated from api/openapi.yaml (or hand-written Axios wrapper)
  • State: server state in TanStack Query; local UI state in React context or Zustand
  • Real-time: approvals page subscribes to gateway WebSocket
